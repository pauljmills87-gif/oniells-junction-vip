ANDROID HOME-SCREEN BLACK GAP FIX — ONE ADD-ON FILE

1) Extract android-screen-fix.js into the root folder of your
   oniells-junction-vip project (alongside index.html and vip-install.js).

2) In index.html, find the single closing </head> tag.
   Insert ONE new line immediately before it:

   <script src="/android-screen-fix.js" defer></script>

3) Save, then in the VS Code terminal run:
   git add -A
   git commit -m "Fix Android home screen black gap"
   git push origin main

4) When Vercel is Ready, refresh the website on Android Chrome.

WHAT THIS DOES
- On Android screens narrower than 540px, makes the approved home
  image and its clickable venue buttons fill the visible screen height.
- Changes nothing on iPhone, or on the login, membership card, or admin pages.
- Does not touch vip-install.js or the OneSignal worker.

NOTE: To fill taller Android screens without clipping text or clickable
buttons, the home artwork scales vertically to fit. If you later prefer
an undistorted crop/extended-background treatment, that can be designed
separately for Android aspect ratios.
